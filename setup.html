PRODUCTION SETUP

Connect REAP LIFE to its cloud backend.

This page explains the final connection step. No secret service-role key belongs in this website.

  1. Create a Supabase project.
  2. The REAP LIFE database schema is already installed in your Supabase project.
  3. Create the first Authentication user.
  4. Open bootstrap-admin.html while signed in to make the first account the administrator.
  5. Put the project URL and publishable key into assets/reap-config.js.
  6. Deploy the repository through GitHub + Cloudflare Pages.
Why the configuration is blank: the project credentials belong to your Supabase account. Leaving placeholders here prevents us from pretending the backend is already connected.
